# 🌦 Projet API – Météo

## 📘 Description

Script Python permettant de collecter des données météo via l’API Open-Meteo et de les stocker dans un fichier CSV horodaté.

---

## 🔧 Fonctionnalités

- Appel API REST Open-Meteo
- Extraction température et vitesse du vent
- Ajout de la date/heure d’exécution
- Écriture en CSV (append + header automatique)

---

## 🧩 Fichiers

- `meteo.py` : collecte et logging des données
- `analyse_meteo.py` : analyse simple avec pandas
- `meteo.csv` : données générées

---

## 🎯 Objectif pédagogique

Comprendre et maîtriser un pipeline simple :
**API → JSON → CSV → analyse**
