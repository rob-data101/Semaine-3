# 🧬 Projet API – PokéAPI (Pokédex)

## 📘 Description

Script Python utilisant la PokéAPI pour construire un mini-dataset Pokémon exploitable et analysable.

---

## 🔧 Fonctionnalités

- Appel API PokéAPI
- Extraction des données clés :
  - nom
  - taille (cm)
  - poids (kg)
  - type principal
- Horodatage et stockage en CSV
- Analyse de données avec pandas

---

## 📊 Analyse réalisée

- Top Pokémon les plus lourds (par entité)
- Type le plus représenté
- Type le plus lourd en moyenne
- KPIs de taille (mean / min / max)
- Nombre total d’appels API
- Nombre de Pokémon uniques

---

## 🧩 Fichiers

- `pokemon.py` : collecte API + CSV
- `analyse_pokedex.py` : analyse pandas
- `pokedex.csv` : dataset généré

---

## 🎯 Objectif pédagogique

Passer de la collecte brute à une **analyse de données exploitable**.
