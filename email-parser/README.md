# ✉️ Projet Python – Email Parser → JSON

## 📘 Description

Parser Python permettant de transformer un email brut non structuré en données exploitables.

---

## 🔧 Fonctionnalités

- Lecture d’un email texte
- Nettoyage du contenu (signatures, formules, bruit)
- Extraction de mots-clés (règles simples)
- Génération d’un fichier JSON structuré
- 1 email = 1 JSON

---

## 🧩 Fichiers

- `email_parser.py` : script principal
- `examples/` : emails d’exemple
- `json/` : JSON générés

---

## 🎯 Objectif pédagogique

Préparer des données non structurées pour :
- automatisation
- classification
- résumé IA
